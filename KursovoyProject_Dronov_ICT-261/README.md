# Расчёт давления в компрессорной установке
### Постановка задачи
Составить программу, которая, согласно указанным формулам при разных значениях "x", будет вычислять показатель давления (в барах) компрессорной установки, а также среднее, медиану, первый максимум и количество локальных минимумов из всех получившихся значений.
## Входные данные
x - целое число, от которого зависит итоговое значение Q (давление компрессорной установки)

lcl и ucl - нижняя и верхняя границы допустимого значения Q (целые числа)
## Формула
При $x<-10$ формула принимает вид:

$Q(x) = 0$

При $x>=-10$ и $x<5$ формула принимает вид:

$Q(x) = 4x + 5$

При $x>=5$ и $x<10$ формула принимает вид:

$Q(x) = 2x + 15$

При $x>=10$ формула принимает вид:

$Q(x) = x + 25$
## Контрольный пример
При $x=0$: $Q(x) = 5$

При $x=5$: $Q(x) = 25$

При $x=20$: $Q(x) = 45$
